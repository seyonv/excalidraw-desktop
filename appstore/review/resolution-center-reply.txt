SUMMARY
Sketchshelf is a free, offline Mac drawing app. It has no account or sign-in, no in-app purchases, no ads, no user-generated content sharing, and it makes no network requests. A screen recording of the full flow is attached to the Resolution Center reply for this version.

1. SCREEN RECORDING
Recorded on a physical MacBook Air (M3) running macOS 27.0.1, not a virtual machine, starting from launch in Finder. Tested on that Mac with the same build. It covers creating a drawing, drawing on it, autosave, switching drawings, rename, text emphasis, export to PNG, File → Open, dark mode, delete, and quit and relaunch. The app has no registration, login, account deletion, sharing, reporting or paid features, so none appear.

2. PURPOSE AND AUDIENCE
Sketchshelf is a library for hand-drawn diagrams, sketches and whiteboards. It is for people who sketch to think: developers drawing architecture, designers wireframing, students and writers mapping ideas. The open-source Excalidraw editor it is built on runs in a browser tab and holds one drawing at a time. Sketchshelf gives every drawing its own file in a sidebar library, saves as you draw, and lets you switch between drawings in one click. Drawings stay on the user's Mac as standard .excalidraw files.

3. HOW TO USE IT (no login or sample files needed)
On first launch, the library opens with a blank drawing.
a. Draw on the canvas. It saves automatically about a second after you stop.
b. Click "+ New drawing" in the sidebar, then click between drawings to switch.
c. Double-click a drawing's name to rename it. Delete it from the ⋯ menu on its row.
d. Press T, click the canvas and type a sentence. Then ⌘-double-click the text to open the rich-text editor, select a word, and press ⌘B (blue) or ⌘U (underline).
e. ☰ menu → Export image saves a PNG or SVG through the system Save panel.
f. ☰ menu → Open… (⌘O) adds existing .excalidraw files to the library.
g. ☰ menu → Dark mode switches the whole app to dark mode.
Drawings are stored inside the app's sandbox container. They survive quitting and relaunching.

4. EXTERNAL SERVICES
None. No analytics, crash reporting, authentication, payment, AI or cloud services. The editor's code and fonts are bundled inside the app. The only third-party code is the open-source Excalidraw editor (MIT licence, bundled), plus the Tauri and React frameworks. Help links in Excalidraw's menu open in the user's default browser. The app never fetches them itself.
The app has a strict Content-Security-Policy that blocks every outside connection, iframe and remote script. Excalidraw's optional online features (publishing a library, web embeds) cannot reach the internet from inside Sketchshelf.
The com.apple.security.network.client entitlement is there only because WebKit's networking process will not start inside the sandbox without it.

5. REGIONAL DIFFERENCES
None. The app works the same in every region. It is in English and has no region-specific content or features.
