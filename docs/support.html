Support

Found a bug or have an idea? Email seyon.vasantharajan@gmail.com or open an issue on GitHub.

Where are my drawings stored?

Inside the app's folder at ~/Library/Containers/dev.seyon.sketchshelf/Data/Library/Application Support/Excalidraw. Each drawing is a standard .excalidraw file named after the drawing.

How do I get a drawing out?

Open the ☰ menu on the canvas. Export image saves a PNG or SVG, and Save to… saves a copy of the .excalidraw file anywhere you choose.

How do I bring existing drawings in?

Double-click any .excalidraw file in Finder, or use File → Open… (⌘O) to pick several at once. A copy is added to your library; the original is left untouched.

How do I style part of a text block?

Select a text element and press ⌘B (blue), ⌘1/⌘2/⌘3 (red, green, orange), ⌘H (highlight), ⌘U (underline) or ⌘E (box). Double-click a styled block to edit it and style individual phrases.

I deleted a drawing by mistake

The app keeps the last 20 saved versions of each drawing in a hidden .history folder next to your drawings. Email us and we will walk you through restoring one.
