Where are my drawings stored?

On your Mac, as standard .excalidraw files named after each drawing. Where depends on which copy you installed:

  • Direct download: ~/Library/Application Support/Excalidraw
  • Mac App Store: ~/Library/Containers/dev.seyon.sketchshelf/Data/Library/Application Support/Excalidraw

The two copies keep separate libraries. If you switch from one to the other, open the old folder in Finder and drag your drawings onto the new app, or use File → Open….

How do I get a drawing out?

Open the ☰ menu on the canvas. Export image saves a PNG or SVG, and Save to… saves a copy of the .excalidraw file anywhere you choose.

How do I bring existing drawings in?

Double-click any .excalidraw file in Finder, or use File → Open… (⌘O) to pick several at once. A copy is added to your library; the original is left untouched.

How do I style part of a text block?

Hold ⌘ and double-click any text to open the editor. Select a word, then press ⌘B (blue), ⌘1/2/3 (red, green, orange), ⌘H (highlight), ⌘U (underline) or ⌘E (box). ⌘\ clears the styling. A note that's already styled opens the editor on a plain double-click.

How do I get updates?

The Mac App Store copy updates itself. The direct download doesn't yet, so check this site for new versions and download again. Your drawings stay where they are.

I deleted a drawing by mistake

The app keeps the last 20 saved versions of each drawing in a hidden .history folder next to your drawings. To get one back, open the folder above in Finder, press ⌘⇧. to show hidden files, and look in .history/<drawing name>. Each .bak file is a full copy of the drawing: rename one to end in .excalidraw and open it with File → Open…. Or email us and we'll walk you through it.
